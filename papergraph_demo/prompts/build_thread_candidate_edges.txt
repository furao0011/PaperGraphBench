You are constructing cross-Macro Thread candidate edges for a paper evaluation graph.

Given the Macro Spine, KCs, and already verified lower-layer edges, propose candidate edges that can support multi-step reasoning threads across the paper.

Some KCs may come from virtual multimodal Units generated from figures or tables. Their source text contains the asset caption, asset summary, evidence bases, and supported KC claims. Use only that provided text as evidence.

Allowed relations:
- part_of
- defines
- motivates
- solves
- explains
- supports
- contrasts_with
- limits

Useful thread patterns:
- problem -> method
- method -> mechanism
- method or mechanism -> experiment result
- module -> ablation
- claim -> limitation
- baseline -> comparison result

Rules:
1. Use only KC IDs present in `valid_kc_ids`. The `source` and `target` values must exactly match those IDs.
2. Prefer cross-Macro edges. Do not recreate Unit-internal or Macro-internal edges.
3. Do not create generic topical similarity edges.
4. Every edge must include `evidence_unit_id` and `evidence_paragraph_ids` selected from either the source KC Unit paragraphs or the target KC Unit paragraphs. Do not rewrite evidence text.
5. Preserve direction according to the reasoning pattern.
6. Use the lower-layer verified edges as hints, not as permission to invent unsupported edges.
7. Use English in all generated fields.
8. Return JSON only.

Input:

```json
{{thread_context_json}}
```

Return strict JSON:

```json
{
  "edges": [
    {
      "source": "KC12",
      "target": "KC31",
      "relation": "supports",
      "thread_pattern": "method_to_result",
      "evidence_unit_id": "U_S4_001",
      "evidence_paragraph_ids": ["P1"],
      "reason": "brief explanation of why this edge can support a reasoning thread",
      "confidence": 0.84
    }
  ]
}
```

```json

  "edges": []
}
```
