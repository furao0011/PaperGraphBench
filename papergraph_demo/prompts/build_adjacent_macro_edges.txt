You are constructing adjacent-Macro reasoning edge candidates for a paper evaluation graph.

Given a directed Macro edge and representative KCs from the source and target Macros, create candidate edges that explain how the paper's main argument progresses from the source Macro to the target Macro.

Allowed relations:
- part_of
- defines
- motivates
- solves
- explains
- supports
- contrasts_with
- limits

Typical adjacent-Macro progressions:
- problem Macro -> method Macro
- method Macro -> experiment/result Macro
- experiment/result Macro -> conclusion/limitation Macro

Rules:
1. Use only KC IDs present in the input.
2. Source KC must come from the source Macro, and target KC must come from the target Macro.
3. Do not create generic topical similarity edges.
4. Every edge must include a verbatim evidence span from either the source KC Unit text or the target KC Unit text.
5. Preserve direction from the source Macro to the target Macro.
6. Use English in all generated fields.
7. Return JSON only.

Input:

```json
{{adjacent_macro_context_json}}
```

Return strict JSON:

```json
{
  "edges": [
    {
      "source": "KC12",
      "target": "KC31",
      "relation": "motivates",
      "evidence": "verbatim evidence span from source or target Unit text",
      "reason": "brief explanation of how the source Macro claim advances to the target Macro claim",
      "confidence": 0.84
    }
  ]
}
```

```json

  "edges": []
```
